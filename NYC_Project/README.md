NYC Taxi Analytics: Serverless Medallion Architecture on GCP
🚕 Project Overview
This project demonstrates an end-to-end data engineering pipeline designed to process and analyze millions of NYC Taxi records. Using Google Cloud Platform (GCP) and Power BI, I engineered a scalable, serverless solution that transforms raw data into actionable logistics insights through a Medallion Architecture.

The goal was to move beyond basic visualization by building a "future-proof" data foundation that ensures Data Quality and Single Source of Truth for professional stakeholders.

🛠 Technical Architecture
The pipeline follows a three-layer Medallion Architecture to ensure data reliability and transparency:
Bronze (Raw Layer): Automated ingestion of millions of records into BigQuery raw tables, maintaining the original source schema.

Silver (Cleaned Layer): Implemented Data Cleansing logic to handle missing values and outliers, ensuring consistency for technical data flows.

Gold (Semantic Layer): Designed an optimized Star Schema model specifically to power high-performance Power BI dashboards for business-ready results.

🚀 Key Features & Skills Demonstrated
GCP Big Data Stack: Leveraged BigQuery for serverless data warehousing and high-speed SQL processing.

Data Flow Optimization: Streamlined the movement of data from source systems to the platform, reflecting professional data management practices.

Semantic Layer Design: Built a business-ready layer that minimizes reporting discrepancies, similar to the "Single Source of Truth" architectures I managed at Unilever.

Logistics Visibility: Visualized key metrics such as trip density, revenue trends, and vendor efficiency to provide a professional perspective on data flows.
